# OFX prototype

Interactive research prototype. No real purchases, payments or messages are sent.

Static HTML, CSS and JavaScript; no build step or server-side services required.
To preview locally: `python3 -m http.server 4173`, then open localhost:4173.

GitHub Pages publishes the root of the `main` branch. To take the public website
offline after the interviews, use Settings → Pages → Unpublish site.
Unpublishing does not delete this public repository or copies already downloaded.
